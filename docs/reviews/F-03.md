## M1 — Medium: returned master contracts do not enforce their kind

References: `packages/contracts/src/masters.ts:38–60`;
`apps/api/tests/unit/f03-master-contracts.test.ts:101–115`;
`specs/004-master-data/spec.md:58–60`.

violation types, locationId on gates. The shared response schema is instead one
object with all those fields optional regardless of kind. A department can carry
severity or locationId, and a list with `kind: 'departments'` accepts a gate row.

explicitly expects a department with severity to be valid at line 104, contrary
to that name and the frozen spec. Passing counts cannot establish the promised
shared response contract.
